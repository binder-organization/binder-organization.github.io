## 如何发表文章

基本流程是：准备中英文 Markdown 稿，转换为文章 JSON，本地预览，然后提交文章 JSON 和更新后的索引到 `assets/articles/`。Front Matter 格式、支持的 Markdown、本地预览和审核要求详见[文章投稿指南](docs/article-publishing_zh-CN.md)。
